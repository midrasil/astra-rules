# Creature Types

The **Creature Type** classifies the nature of a character or creature. The default is **Humanoid**.

The starting list of types is:

- **Humanoid**
- **Beast**
- **Monstrosity**
- **Undead**
- **Construct**
- **Elemental**
- **Spirit**
- **Aberration**
- **Plant**
- **Dragon**

Each creature has **a single Type**: the one that best describes what it is now. An undead dragon, for example, is Undead.

Creature Type only has an effect when a rule refers to it, such as the [Hunter](../Compet%C3%AAncias/Ca%C3%A7ador.md). Otherwise, it serves as a reference for the Narrator and as a basis for future rules, such as Capabilities, Resistances or effects that affect only certain types. Settings and modules can add new types and must say how the rules that refer to types treat them.
