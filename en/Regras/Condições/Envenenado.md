# Poisoned

A **Poisoned** character gets:

> **-2 dice on rolls that use a Physical Attribute**

The condition lasts the number of Turns the source sets. With the **Venomous** NPC Capability (see [NPC Capabilities](../Capacidades/Capacidades%20de%20NPC.md)), that number equals the poison's Potency.

Poisoned can be applied by Capabilities, items or other effects that refer to this Condition.
