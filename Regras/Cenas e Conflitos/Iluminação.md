A **Iluminação** de uma área afeta as rolagens que dependem de enxergar, como atacar, perceber ou procurar algo.

O Narrador define a iluminação de cada área.

| Iluminação | Penalidade |
|---|---|
| **Claro** | nenhuma |
| **Penumbra** | -2 dados |
| **Escuro** | -4 dados |
| **Breu** | -6 dados |

Uma criatura com **Visão no Escuro** enxerga, até o alcance dela, o Escuro como Penumbra e a Penumbra como Claro. O Breu bloqueia a Visão no Escuro (ver [Características de NPC](../Personagens/Trunfos/Caracter%C3%ADsticas%20de%20NPC.md)).
