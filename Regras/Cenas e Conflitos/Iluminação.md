A **Iluminação** de uma área afeta as rolagens que dependem de enxergar, como atacar, perceber ou procurar algo.

O Narrador define a iluminação de cada área.

| Iluminação | Penalidade |
|---|---|
| **Claro** | nenhuma |
| **Penumbra** | -2 dados |
| **Escuro** | -4 dados |
| **Breu** | -6 dados |

Uma criatura com **Visão no Escuro** ignora as penalidades de Penumbra e de Escuro, mas não as de Breu (ver [[Características de NPC]]).
